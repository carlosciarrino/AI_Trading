# AI_BRIDGE V2

## Trading Operating System

AI_BRIDGE V2 è un Trading Operating System modulare progettato per costruire un'infrastruttura professionale dedicata al trading algoritmico.

Il progetto è sviluppato secondo principi di modularità, responsabilità unica, stabilità delle API e utilizza esclusivamente la Python Standard Library.
