# AI_BRIDGE V2 — Configuration Architecture

## Scopo del documento

Questo documento definirà l'architettura del sistema di configurazione di AI_BRIDGE V2.

La configurazione deve permettere al sistema di adattarsi senza modificare il codice sorgente.

---

## Principi

- Separazione tra codice e configurazione.
- Configurazione esplicita e documentata.
- Nessun valore critico hardcoded negli engine.
- Compatibilità con evoluzioni future del sistema.

---

## Stato attuale

La configurazione base del progetto è gestita tramite i file YAML presenti nel repository.

L'evoluzione futura definirà:
- schema configurazione;
- validazione;
- gestione ambienti;
- configurazioni broker e strategie.

---

## Stato documento

Documento iniziale.
Da completare nella fase di evoluzione della configurazione AI_BRIDGE V2.
